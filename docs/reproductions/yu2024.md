# Yu et al. 2024

## Implementation

A 2D ResNet34 classifies every tumor slice, and the slices are combined per volume by hard voting (the share of malignant slices) or soft voting (the mean weighted by tumor voxels, Eq. 1).

- `abus_classification/papers/yu2024/model.py`: `YuResNet`, grey slices repeated to three channels.
- `abus_classification/papers/yu2024/pipeline.py`: `tumor_slices` and `build_cache` extract slices, `train_run` trains, `votes` and `evaluate` combine and score, `cv` repeats the paper's protocol, `main` runs everything.
- `test/papers_tests/test_yu2024.py`: slice extraction, hand-computed votes, parameter count, overfit run with a stand-in network.

Data flow: TDSC volumes and masks go to `data/yu2024.npz` (whole slices, lesion crops, voxels per slice), then to one training per mode and seed, then to slice probabilities and per-volume votes.

Main decisions: only ResNet34 was run, and the paper gives no optimizer, input size, pretraining or augmentation. We use Adam, lr 1e-4, batch 32, 224 x 224 and no augmentation, and run lesion crops and no pretraining as variants. Voting weights and crops use ground-truth masks. The full list is in Section 2 of [`6-yu2024.ipynb`](../../notebooks/6-yu2024.ipynb).

## Requirements

- TDSC-ABUS Train, Validation and Test, as the private Kaggle datasets `tdsc-abus2023-trainval` and `tdsc-abus2023-test`. The cache is built by the run and is not kept.
- Training: a Kaggle GPU. The notebook runs on a laptop from stored results.
- Local Test masks, only to rebuild `results/yu2024/yu2024_test_slices.npz`.

## Reproducing the results

Kernel `mralinp/yu2024-voting` (`kaggle/yu2024/`) clones `feat/yu2024`, reads the two datasets, and writes per-run `.npz` probabilities, `_history.csv`, `.pt` weights and `yu2024_results.csv`. Settings are the defaults of `main`: all three modes, seeds 0, 1 and 2, 100 epochs, plus five-fold CV for the two pretrained modes (19 trainings). It took about 10 h.

```bash
python kaggle/push.py yu2024
```

The download used, with the kernel's account token in `KAGGLE_API_TOKEN`:

```bash
kaggle kernels output mralinp/yu2024-voting -p results/yu2024 --file-pattern '.*(csv|npz)$'
```

`yu2024_test_slices.npz` holds each test slice's case and voxel count and each volume's label. The run did not save it, so it was rebuilt from the local Test masks by a one-off script, not kept in the repository. Then run the notebook.

## Expected results

Means of 3 seeds on Test, soft voting: whole slices AUC 0.745 (seed SD 0.039), lesion crops 0.812 (0.005), no pretraining 0.665 (0.055). Five-fold CV on Train, soft voting: whole slices 0.709, lesion crops 0.846. Full tables are in Section 5 of the notebook, and the stored results are in `results/yu2024/`.

Early stopping (`yu2024_es_*`), ensemble AUC against the paper defaults: crops 0.825 against 0.825, whole slices 0.676 against 0.765, no pretraining 0.705 against 0.687. All paired 95% intervals include zero. It fits Train only (100 volumes), against 130 for the defaults. Five-fold CV, soft voting: whole slices 0.645, crops 0.815. Challenge benchmark, classification only, crops: rank 4 of 9 (Cls_Score 0.734) with defaults, 3 of 9 (0.767) with early stopping.

The early-stopping run used `kaggle/yu2024-early-stopping/`, started from Kaggle's editor because of its Drive secret. Its output was copied from `abus-checkpoints/yu2024-early-stopping` on Drive with `rclone`, without weights or checkpoints.
