# TDSC-ABUS challenge, team T1 (SZU)

## Implementation

The paper (Luo et al., arXiv:2501.15588, Sec. 3.2.1) gives three model families and no further detail. We build a fully automatic pipeline that uses no ground truth at test time.

- `abus_classification/papers/luo2025_t1/model.py`: `CLSNet` (3D ResNet-18), `SEGNet` (3D U-Net), `DETNet` (anchor-free heatmap, offset and size).
- `abus_classification/papers/luo2025_t1/pipeline.py`: `build_cache`, `train_det`, `train_seg`, `train_cls`, the shared `train` loop with checkpoints, `evaluate`, `main`.
- `test/papers_tests/test_luo2025_t1.py`: shapes, hand-computed loss, box and mask conversion, resume, and all tasks on synthetic volumes.

Data flow: TDSC volumes go to `data/luo2025_t1.npz` at 0.5 mm. DETNet trains on whole volumes at 1 mm and SEGNet on patches. CLSNet trains on patches around the true centre, moved up to 12 voxels, and on Test reads the patch around the same seed's top detected box. Masks and boxes return to the original grid for the challenge's metrics (`abus_classification/challenge.py`).

Main decisions: everything beyond the model families is assumed, and each training fits Train only, using Validation for early stopping and the learning rate. The full list is in Section 2 of [`7-luo2025-t1.ipynb`](../../notebooks/7-luo2025-t1.ipynb).

## Requirements

- TDSC-ABUS Train, Validation and Test, as the private Kaggle datasets `tdsc-abus2023-trainval` and `tdsc-abus2023-test`. The cache is built by the run and is not kept.
- Training: Kaggle T4 x 2. CPU works only for the tests, and MPS lacks 3D convolutions. The notebook runs on a laptop from stored results.
- The private Kaggle dataset `rclone-conf` on the kernel's account, holding `rclone.conf.b64`, a base64-encoded rclone config with a `gdrive` remote. Share it with nobody: it holds a Drive token.

## Reproducing the results

```bash
uv run pytest test/papers_tests/test_luo2025_t1.py
python kaggle/push.py luo2025-t1 --accelerator NvidiaTeslaT4
```

The kernel clones `feat/luo2025-t1`, reads the two datasets, and syncs its output to `abus-checkpoints/luo2025-t1` on Drive every 10 minutes: per-run `.npz` predictions, `_history.csv`, `.ckpt` checkpoints, `.pt` weights, `luo2025_t1_progress.log`, `luo2025_t1_results.csv` and `luo2025_t1_benchmark.csv`. A restarted kernel downloads them and resumes. Training stops at 10 h so the kernel ends before the 12 h limit. Run time: not run yet.
