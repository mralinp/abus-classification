# TDSC-ABUS challenge, team T1 (SZU)

## Implementation

The paper (Luo et al., arXiv:2501.15588, Sec. 3.2.1) gives three model families and no further detail. We build a fully automatic pipeline that uses no ground truth at test time.

- `abus_classification/papers/luo2025_t1/model.py`: `CLSNet` (3D ResNet-18), `SEGNet` (3D U-Net), `DETNet` (anchor-free heatmap, offset and size).
- `abus_classification/papers/luo2025_t1/pipeline.py`: `build_cache`, `train_det`, `train_seg`, `train_cls`, the shared `train` loop with checkpoints, `evaluate`, `main`.
- `test/papers_tests/test_luo2025_t1.py`: shapes, hand-computed loss, box and mask conversion, resume, and all tasks on synthetic volumes.

Data flow: TDSC volumes go to `data/luo2025_t1.npz` at 0.5 mm. DETNet trains on whole volumes at 1 mm and SEGNet on patches. CLSNet trains on patches around the true centre, moved up to 12 voxels, and on Test reads the patch around the same seed's top detected box. Masks and boxes return to the original grid for the challenge's metrics (`abus_classification/challenge.py`).

Main decisions: everything beyond the model families is assumed, and each training fits Train only, using Validation for early stopping and the learning rate. The full list is in Section 2 of [`7-luo2025-t1.ipynb`](../../notebooks/7-luo2025-t1.ipynb).

## Requirements

- TDSC-ABUS Train, Validation and Test, as the private Kaggle datasets `tdsc-abus2023-trainval` and `tdsc-abus2023-test`. The cache is built by the run and is not kept.
- Training: Kaggle T4 x 2. CPU works only for the tests, and MPS lacks 3D convolutions. The notebook runs on a laptop from stored results.
- The Kaggle secret `RCLONE_CONF`, a base64-encoded rclone config with a `gdrive` remote.

## Reproducing the results

```bash
uv run pytest test/papers_tests/test_luo2025_t1.py
python kaggle/push.py luo2025-t1 --accelerator NvidiaTeslaT4
```

Attach `RCLONE_CONF` to the kernel, start it from Kaggle's editor with Save & Run All, and stop the editor session. The kernel clones `feat/luo2025-t1`, reads the two datasets, and syncs its output to `abus-checkpoints/luo2025-t1` on Drive every 10 minutes: per-run `.npz` predictions, `_history.csv`, `.ckpt` checkpoints, `.pt` weights, `luo2025_t1_progress.log`, `luo2025_t1_results.csv` and `luo2025_t1_benchmark.csv`. A restarted kernel downloads them and resumes. Training stops at 10 h so the kernel ends before the 12 h limit. Run time: about 6.4 h on T4 x 2, including the 16-minute cache.

### Detect then segment

Our change after the run, with no retraining: SEGNet on one patch at DETNet's top box instead of sliding windows.

```bash
python -m abus_classification.papers.luo2025_t1 --detect-then-segment <weights_dir> --out-dir results/luo2025_t1
```

| Dice | Seed 0 | Seed 1 | Seed 2 | Mean |
|---|---|---|---|---|
| Validation, first 10 volumes, sliding windows | 0.132 | 0.079 | 0.060 | 0.090 |
| Validation, same 10 volumes, patch | 0.598 | 0.662 | 0.587 | 0.615 |
| Validation, all 30 volumes, patch | 0.542 | 0.506 | 0.522 | 0.523 |
| Test, patch | 0.485 | 0.470 | 0.463 | 0.473 |

Test HD is 108.4 against the stored run's 254.8 and T1's 117.2, with 3, 0 and 0 empty masks. Segmentation rank moves from 15/15 to 10/15; overall stays 8/8.

Read these with care. We decided to try this after seeing Test (#64), although Validation then chose it on its own numbers. HD penalises an empty mask with our own worst case, not the worst across teams, which flatters us slightly. It finds one lesion per volume, which suits this data but is an assumption. The stored run stays the main result.

## Status

- Unit tests pass, and all three models trained on Kaggle with checkpoints and final weights on Drive.
- Segmentation (#64): the fault is in our sliding-window inference, not the weights. On one patch, whole-volume Dice at 0.5 mm with the stored weights is 0.489, 0.454, 0.463 on DETNet's top box and 0.600, 0.563, 0.605 on the true lesion (`luo2025_t1_seg_inference_diagnostic.csv`, a scratch run on Test, not a result; see Detect then segment above). Cached-grid and original-grid Dice agree, so resampling is not the cause.
- Classification (#65): validation AUC 0.855-0.891, true-centre Test AUC 0.65-0.75, lesion volume alone 0.741.
- Detection (#66): top box IoU above 0.3 in 36-43 of 70 volumes.
- Round-tripping true masks of 2 test volumes through the 0.5 mm grid gave Dice 0.93 and 0.89, so this grid limits Dice on small lesions.
- Fixed before the stored run: DETNet's volumes stayed on the CPU, and sliding-window validation took most of each SEGNet epoch. SEGNet now selects its epoch by Dice on the patch around the true lesion, which ignores false positives elsewhere.
- Short smoke runs on Kaggle died silently; the cause was not found and the full run did not show it.
- Not implemented: test-time augmentation, ensembling for segmentation and detection, and the other teams (#31, #32, #33).
